# 👋 Welcome to IK-Online

**IK-Online** is a multi-tenant SaaS platform built for the Norwegian restaurant and hospitality industry.  
We turn fragmented compliance work — food safety logs, HSE documentation, temperature checks — into structured digital workflows accessible from any device.

---

## 🏢 What We Build

Restaurants and food-service businesses have long relied on paper binders, spreadsheets, and disconnected apps to manage internal control. IK-Online replaces all of that with a **single, unified platform** that covers:

- 🥗 **IK-mat** — Food safety and HACCP-based routines
- 🌡️ **Temperature Logging** — Digital logging with future IoT sensor integration
- 🦺 **HSE** — Health, safety, and environment documentation
- 📋 **Deviation Reporting** — Track and follow up on non-conformances
- 👥 **HR & Staff Management** — Employee overview and onboarding flows
- 📅 **Annual Cycles** — Structured yearly compliance workflows
- 📲 **Scan-to-Action** — QR/NFC-based hygiene and equipment checks

## 🧰 Tech Stack

| Layer | Technology |
|---|---|
| Language | TypeScript |
| Monorepo | Turborepo + Bun |
| Web (Platform) | React, TanStack Router, shadcn/ui |
| Mobile | Expo Router, React Native |
| Backend | Hono, tRPC |
| Database | Neon (Serverless Postgres) + Drizzle ORM |
| Auth | Better-Auth (multi-tenant) |
| Payments | Stripe |
| Infrastructure | Cloudflare Workers, Pages |

## 🎯 Our Goal

> Give every Norwegian restaurant a single place to open in the morning and see everything that matters — compliance status, active tasks, staff, and financials.  
> **No binders. No spreadsheets. One platform.**

---

## 🌍 Target Market

Norwegian restaurants, hotel kitchens, catering companies, and food-service SMBs that are required to document internal control under Norwegian food safety regulations (Mattilsynet / Næringsmiddeltilsynet).
